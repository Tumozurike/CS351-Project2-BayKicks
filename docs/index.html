BayKicks — Project 2

CS351 full-stack sneaker storefront: React/Vite, Express, MongoDB Atlas and Cloud Run.

Architecture

React UI → fetch('/api/...') → Express routes → controllers → MongoDB collections. Express sessions persist the cart and logged-in user ID.

Key folders

client/src/views pages; client/src/api.js HTTP; server/routes endpoints; server/controllers business logic; server/models schemas.

How to run

Follow the root README. Configure MongoDB, seed products, start Express and Vite. Never publish secrets.

Demo checklist

  1. Create account; show users collection before/after
  2. Log in, edit account, and view orders
  3. Add different sneakers to cart, refresh, adjust quantities, remove
  4. Checkout using fake last four digits; show orders collection before/after
  5. Demonstrate Cloud Run and GitHub Wiki videos
