# BayKicks — CS351 Project 2

Welcome to the BayKicks Project 2 Wiki!

BayKicks is a full-stack sneaker shopping application developed using React, Vite, Node.js, Express, and MongoDB Atlas.

## Project Overview

The application allows users to browse sneakers, create accounts, log in, manage shopping carts, complete simulated purchases, and view order history.

## Technologies Used

- **Frontend:** React and Vite
- **Backend:** Node.js and Express
- **Database:** MongoDB Atlas
- **Deployment:** Google Cloud Run
- **Version Control:** GitHub

## Project Demonstrations

The following demonstrations are included in our complete project video:

1. **Account Creation and Login** — Register users and demonstrate MongoDB account storage.
2. **Shopping Cart** — Add products, update quantities, remove items, and demonstrate cart persistence.
3. **Checkout and Orders** — Complete a simulated purchase and verify order information in MongoDB.
4. **Code Walkthrough** — Explain the frontend, backend, API routes, and database models.
5. **Database Overview** — Demonstrate MongoDB Atlas collections for products, users, and orders.
6. **Cloud Deployment** — Explain Docker and Google Cloud Run deployment.
